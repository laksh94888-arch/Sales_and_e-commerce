# Dataset Documentation & Source Attribution

## 1. Dataset Overview

This project uses the genuine **Sample Superstore Sales Dataset**, a widely recognized benchmark dataset originally published for enterprise sales analytics and business intelligence benchmarking (e.g., Tableau, Power BI, and Python analytics portfolios).

- **Filename (CSV):** `sample_sales_data.csv`
- **Filename (XLSX):** `sample_sales_data.xlsx` (Excel sample for quick upload testing)
- **Record Count:** 9,994 transactions
- **Feature Count:** 21 attributes
- **Data Nature:** Real-world retail and enterprise e-commerce sales transactions across the United States.
- **Format:** Comma-Separated Values (CSV) and Microsoft Excel (XLSX).

## 2. Dataset Source & Attribution

- **Public Repository Source:** [Gist / Tableau Public Superstore](https://gist.githubusercontent.com/nnbphuong/38db511db14542f3ba9ef16e69d3814c/raw/3a77ff9d97c504d3ec3210b12fde7242b8c6ab63/Superstore.csv)

## 3. Data Dictionary (21 Columns)

| Column Name | Data Type | Analytical Role | Description |
| :--- | :--- | :--- | :--- |
| **Row ID** | Integer | Identifier | Unique sequential row index (1 to 9,994). |
| **Order ID** | String | Identifier | Unique transaction code (e.g., `CA-2016-152156`). |
| **Order Date** | Date / DateTime | Temporal | Date the customer placed the order (YYYY-MM-DD). |
| **Ship Date** | Date / DateTime | Temporal | Date the shipment was dispatched. |
| **Ship Mode** | Categorical | Operational | Delivery tier (`Standard Class`, `Second Class`, `First Class`, `Same Day`). |
| **Customer ID** | String | Identifier | Unique identifier for individual and business clients. |
| **Customer Name** | String | Dimension | Full name of the purchasing customer. |
| **Segment** | Categorical | Market Dimension | Target market (`Consumer`, `Corporate`, `Home Office`). |
| **Country** | Categorical | Geographic | Country (`United States`). |
| **City** | Categorical | Geographic | Destination city. |
| **State** | Categorical | Geographic | Destination US state (e.g., California, New York, Texas). |
| **Postal Code** | Numeric / Text | Geographic | ZIP/postal code of delivery destination. |
| **Region** | Categorical | Geographic | Sales territory (`West`, `East`, `Central`, `South`). |
| **Product ID** | String | Identifier | SKU identifier for catalog merchandise. |
| **Category** | Categorical | Product Hierarchy | Broad product category (`Technology`, `Furniture`, `Office Supplies`). |
| **Sub-Category** | Categorical | Product Hierarchy | Detailed classification (e.g., `Phones`, `Chairs`, `Storage`, `Binds`). |
| **Product Name** | String | Product Hierarchy | Full commercial title and description of the product. |
| **Sales** | Float | Key Financial Metric | Gross revenue from transaction in USD ($). |
| **Quantity** | Integer | Volume Metric | Units sold per order line item. |
| **Discount** | Float | Incentive Metric | Promotional discount applied (0.0 to 0.8 / 0% to 80%). |
| **Profit** | Float | Financial Outcome | Net profit or net loss generated by transaction in USD ($). |
